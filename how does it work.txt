You’re essentially looking at **how data flows from your database all the way to the UI cards** in a Laravel + Livewire + Blade component setup.

Let’s connect everything step by step 👇

---

# 1️⃣ The Main Controller: `Navigation` (Livewire Component)

```php
class Navigation extends Component
```

This is the **brain** of the page.

### What it does:

### ✅ A) Holds State

```php
public $page = 'homes';
public $abidjanListings = [];
public $bouakeListings = [];
public $korhogoListings = [];
public $ferkeListings = [];
```

These properties are:

* Available inside the Livewire view
* Automatically reactive
* Passed into Blade views

---

### ✅ B) Loads Data From Database

```php
private function loadListings()
{
    $this->abidjanListings = Listing::where('location', 'Abidjan')->get();
    ...
}
```

This queries your database via:

```php
use App\Models\Listing;
```

So the data flow starts here:

```
Database → Listing Model → Navigation Component
```

---

### ✅ C) `mount()`

```php
public function mount()
{
    $this->loadListings();
}
```

This runs when the component is first loaded.

So immediately:

```
Page loads → mount() → loadListings() → DB data fetched
```

---

### ✅ D) `render()`

```php
public function render()
{
    return view('livewire.navigation');
}
```

This connects to:

```
resources/views/livewire/navigation.blade.php
```

That’s the main layout view.

---

# 2️⃣ livewire/navigation.blade.php (Main Layout)

This file controls which page is shown:

```blade
@if($page === 'homes')
    @include('homes', [...])
```

It passes the listings:

```blade
'abidjanListings' => $abidjanListings,
```

So now the flow becomes:

```
Navigation.php
    ↓
livewire/navigation.blade.php
    ↓
homes.blade.php
```

---

# 3️⃣ homes.blade.php

This file renders city sections:

```blade
<x-city-section 
    city="Abidjan" 
    :listings="$abidjanListings"
/>
```

So now:

```
homes.blade.php
    ↓
x-city-section component
```

Each city gets its own section component.

---

# 4️⃣ city-section Component

```blade
@props(['city', 'listings'])
```

This component:

* Receives city name
* Receives listings array

Inside it:

```blade
@foreach($listings as $listing)
    <x-listing-card ... />
@endforeach
```

So now:

```
city-section
    ↓
listing-card (for each listing)
```

---

# 5️⃣ listing-card Component

```blade
@props(['image', 'title', 'location', 'price', 'rating', 'animalType'])
```

This is the **final UI card**.

It displays:

* Image
* Title
* Location
* Price
* Rating
* Animal type

So the final flow looks like:

```
Database
   ↓
Listing Model
   ↓
Navigation (Livewire)
   ↓
livewire.navigation
   ↓
homes.blade.php
   ↓
x-city-section
   ↓
x-listing-card
   ↓
User sees UI
```

---

# 6️⃣ How the Scroll Buttons Connect

Inside `city-section`:

```blade
data-target="{{ Str::slug($city) }}-scroll"
```

This creates IDs like:

```
abidjan-scroll
bouake-scroll
```

Then your global JS:

```js
document.querySelectorAll('.scroll-btn-next')
```

Finds the correct container using:

```js
const container = document.getElementById(targetId);
```

So the scroll buttons are dynamically linked to each city section.

That’s a clean reusable system 👌

---

# 7️⃣ How Page Switching Works

Inside `Navigation`:

```php
public function switchPage($page)
{
    $this->page = $page;
}
```

And inside Blade:

```blade
@if($page === 'homes')
```

So when `switchPage()` runs:

* `$page` changes
* Livewire re-renders
* Correct page is shown

That’s Livewire reactivity.

---

# 🎯 In Simple Terms

Your architecture is:

### 🧠 Livewire Component

Handles:

* Data loading
* State
* Page switching

### 🗂 Blade Views

Handle:

* Structure
* Layout
* Passing data downward

### 🧩 Blade Components

Handle:

* Reusable UI pieces

  * city-section
  * listing-card

### 🛢 Model

Handles:

* Database communication

---

# 🧩 Why This Structure Is Good

✔ Separation of concerns
✔ Reusable UI components
✔ Scalable to more cities
✔ Clean data flow
✔ Livewire reactivity

---

# 🚀 If You Want It Even Cleaner

Instead of 4 separate city variables:

```php
public $listingsByCity = [];
```

Then:

```php
$this->listingsByCity = Listing::all()->groupBy('location');
```

Then loop dynamically instead of hardcoding cities.

Much more scalable.
